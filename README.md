# Game Icons

基于 [Nieobie/Game-Icon-Pack](https://github.com/Nieobie/Game-Icon-Pack) 的 SVG 图标集合。

## 在 Markdown 中使用

```markdown
![settings](https://raw.githubusercontent.com/LRedHat233/game-icons/main/1.UI/settings.svg)
```

## 图标分类

| 分类 | 路径 | 说明 |
|------|------|------|
| UI | `1.UI/` | 界面图标（设置、锁定、刷新等） |
| Media & Technology | `2.Media & Technology/` | 媒体与技术图标 |
| Editing Tools | `3.Editing Tools/` | 编辑工具图标 |
| Shapes & Symbol | `4.Shapes & Symbol/` | 形状与符号 |
| Game | `5.Game/` | 游戏相关图标 |
| Items | `6.Items/` | 物品图标 |
